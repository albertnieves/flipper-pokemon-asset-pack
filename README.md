# flipper-pokemon-asset-pack
PokemonEvo — Asset pack for Flipper Zero (Momentum Firmware) featuring all 251 Pokémon from Gen I & II as classic Game Boy sprites, organized into 129 evolution-line animations with an authentic GB-style evolution flash.

Features
  Clean, professional look: centered sprite only — no names, no dex numbers.
  Each animation plays a full evolution line: base Pokémon idles (~4 s, subtle motion), then evolves with a Game Boy-style flash (silhouette + white flicker).
  Branching evolutions included: Eevee shows all 5 Gen II evolutions, Tyrogue all 3, Oddish/Poliwag/Slowpoke both paths.
  Random rotation: the firmware picks a new random line every ~2 minutes (Duration: 120, equal weights).
  Passport icon included (Pikachu).
Install
  Download dist/PokemonEvo.zip (or grab the PokemonEvo/ folder from this repo).
  Open qFlipper → SD Card → asset_packs (create the folder if missing).
  Copy the PokemonEvo folder into SD/asset_packs/.
On the Flipper: press UP → Momentum Settings → Interface → Graphics → Asset Pack → PokemonEvo.
